# 知行证据 · 自适应 AI 学习平台前端原型

这是“可验证的自适应 AI 工程学习平台”的独立前端交互原型，用于确认产品信息架构、页面布局和核心学习流程。

## 当前包含

- 学习项目首页
- 根据资料生成的学习计划
- 今日分步学习
- AI 总结与查看原文切换
- 学习证据提交
- 资料库和三种资料入口
- 带引用的材料问答
- 掌握度与复习队列
- 模型费用、Token、延迟和 Trace 面板

## 当前边界

- 页面数据均为模拟数据。
- 尚未连接 FastAPI 后端、数据库、真实文件上传或 Qwen API。
- 当前仓库只保存前端原型，不包含后端项目代码。
- 正式模型层按产品当前范围只展示 Qwen，不实现第二家云 Provider。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。

## 构建验证

```bash
npm run build
```

构建产物输出到 `dist/`。

## 后续连接后端

正式开发时建议将 API 调用集中到 `src/api/`，并逐步替换当前组件中的模拟数据。前端只通过 HTTP API 与 FastAPI 通信，不直接访问数据库，也不保存模型密钥。
